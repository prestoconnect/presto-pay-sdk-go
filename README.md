# presto-pay-sdk-go

Go SDK for the Presto Pay gateway. Pre-1.0, API may still move.

See [go-plan.md](../go-plan.md) for the design and milestones this repository follows.

## Status

Milestone 1 (scaffold): module, package layout, and CI are in place. The
gateway contract, signing, and the four payment operations are not yet
implemented — see go-plan.md §12 for the milestone list.
